# PDF工具包 - 产品需求文档（PRD）

## 1. 产品背景

### 1.1 项目概述
pdf_tool 是一个基于 Python 的 PDF 处理工具包，旨在提供多种 PDF 相关的实用功能，帮助用户高效处理 PDF 文件。

### 1.2 业务背景
在日常工作和学习中，用户经常需要处理 PDF 文件，如将扫描版 PDF 转换为可编辑文本、提取 PDF 中的特定信息等。目前市场上的 PDF 处理工具存在以下问题：
- 商业软件价格昂贵
- 免费工具功能有限或存在广告
- 在线工具存在隐私泄露风险
- 本地化工具配置复杂

### 1.3 产品目标
构建一个轻量级、本地化、功能丰富的 PDF 处理工具包，满足用户的核心需求。

## 2. 产品定位

- **目标用户**：需要处理 PDF 文件的个人用户、开发者、小型团队
- **核心价值**：免费、开源、本地化、易用性强
- **竞争优势**：基于微信 OCR 引擎，识别准确率高；无需联网，保护隐私；内置资源，开箱即用

## 3. 功能需求

### 3.1 当前功能（v0.5.0）

#### 3.1.1 PDF 转文本功能

**功能描述**：将扫描版 PDF 转换为可编辑的文本文件

**处理流程**：
1. PDF 文件 → 每页转换为 PNG 图片
2. 图片 → 微信 OCR 识别文字
3. 识别结果 → 合并、过滤、保存为 TXT 文件

**功能特性**：
- 支持单文件转换
- 支持批量转换目录中的所有 PDF
- 支持跳过指定页码
- 支持过滤短文本页面（如封面）
- 支持自定义输出目录

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pdf_path | string | 是 | - | PDF 文件路径或包含 PDF 的目录路径 |
| output_dir | string | 否 | PDF 所在目录 | 输出目录 |
| skip_pages | list | 否 | [] | 需要跳过的页码列表（从 0 开始） |
| min_text_length | int | 否 | 50 | 最小文本长度，小于此长度的页面将被忽略 |

**输出结果**：
- 生成与 PDF 同名的 TXT 文件
- 文件编码为 UTF-8

#### 3.1.2 PDF 拆分功能

**功能描述**：将一个 PDF 文件拆分为多个 PDF 文件

**功能特性**：
- 支持每页拆分为一个独立文件
- 支持指定每 N 页一个文件
- 支持指定页码范围拆分
- 自动生成带页码范围的文件名

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pdf_path | string | 是 | - | 要拆分的 PDF 文件路径 |
| output_dir | string | 否 | PDF 所在目录 | 输出目录 |
| pages_per_file | int | 否 | 1 | 每个输出文件的页数 |
| start_page | int | 否 | 1 | 起始页码（从 1 开始） |
| end_page | int | 否 | 最后一页 | 结束页码（从 1 开始） |

#### 3.1.3 PDF 合并功能

**功能描述**：将多个 PDF 文件合并为一个 PDF 文件

**功能特性**：
- 支持合并任意数量的 PDF 文件
- 按传入顺序合并
- 支持自定义输出路径

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pdf_paths | list | 是 | - | 要合并的 PDF 文件路径列表 |
| output_path | string | 否 | 自动生成 | 输出文件路径 |

#### 3.1.4 PDF 删除页面功能

**功能描述**：删除 PDF 文件中的指定页面

**功能特性**：
- 支持删除单个或多个指定页码
- 自动去重和排序页码列表
- 页码范围验证

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pdf_path | string | 是 | - | 要处理的 PDF 文件路径 |
| pages_to_delete | list | 是 | - | 要删除的页码列表（从 1 开始） |
| output_path | string | 否 | 自动生成 | 输出文件路径 |

#### 3.1.5 PDF 转图片功能

**功能描述**：将 PDF 文件转换为图片

**功能特性**：
- 支持多种图片格式（PNG、JPG、JPEG、PPM、TIF、TIFF）
- 支持自定义输出分辨率（DPI）
- 支持指定页码范围转换
- 支持批量转换目录中的所有 PDF 文件

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pdf_path | string | 是 | - | PDF 文件路径或包含 PDF 的目录 |
| output_dir | string | 否 | 自动生成 | 输出目录 |
| image_format | string | 否 | png | 输出图片格式 |
| dpi | int | 否 | 200 | 图片分辨率（DPI） |
| start_page | int | 否 | None | 起始页码（从 1 开始） |
| end_page | int | 否 | None | 结束页码（从 1 开始） |

#### 3.1.6 PDF 压缩功能

**功能描述**：压缩 PDF 文件大小

**功能特性**：
- 支持 5 级压缩级别
- 支持清理 PDF 结构和内容流
- 支持图片优化和重新压缩
- 支持批量压缩目录中的所有 PDF 文件

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pdf_path | string | 是 | - | PDF 文件路径或包含 PDF 的目录 |
| output_path | string | 否 | 自动生成 | 输出文件路径 |
| compression_level | int | 否 | 3 | 压缩级别（1-5） |

**压缩级别说明**：
- **级别 1**：基础压缩，仅清理 PDF 结构
- **级别 2**：压缩内容流
- **级别 3**：优化图片（默认）
- **级别 4**：重新压缩图片
- **级别 5**：高压缩率，可能降低图片质量

#### 3.1.7 PDF 转 Word 功能

**功能描述**：将 PDF 文件转换为 Word 文档

**功能特性**：
- 提取 PDF 中的文本内容
- 支持包含图片提取（可选）
- 保持分页结构
- 支持批量转换目录中的所有 PDF 文件

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pdf_path | string | 是 | - | PDF 文件路径或包含 PDF 的目录 |
| output_path | string | 否 | 自动生成 | 输出文件路径 |
| include_images | bool | 否 | True | 是否包含图片 |

#### 3.1.8 PDF 转 Excel 功能

**功能描述**：将 PDF 文件转换为 Excel 表格

**功能特性**：
- 提取 PDF 中的表格数据
- 支持仅提取表格或提取全部内容
- 自动识别表格结构
- 支持批量转换目录中的所有 PDF 文件

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| pdf_path | string | 是 | - | PDF 文件路径或包含 PDF 的目录 |
| output_path | string | 否 | 自动生成 | 输出文件路径 |
| table_only | bool | 否 | False | 是否仅提取表格 |

### 3.2 规划功能

#### 3.2.1 PDF 加密/解密功能
- 为 PDF 添加密码保护

## 4. 非功能需求

### 4.1 性能要求
- 单页 PDF 转换时间 ≤ 2 秒
- 60 页 PDF 转换时间 ≤ 120 秒

### 4.2 兼容性要求
- 支持 Windows 10/11 系统
- 支持 Python 3.7 及以上版本
- 支持常见 PDF 格式（PDF 1.4 及以上）

### 4.3 可靠性要求
- 识别准确率 ≥ 95%（标准印刷体）
- 支持中英文混排识别

### 4.4 易用性要求
- 提供命令行接口（CLI）
- 提供 Python 库接口
- 支持批量处理
- 详细的错误提示

### 4.5 安全性要求
- 本地处理，不发送数据到云端
- 保护用户隐私

## 5. 用户场景

### 场景一：学术论文处理
**用户角色**：学生/研究员
**场景描述**：用户下载了一篇扫描版的学术论文，需要将其转换为文本以便进行搜索和引用。
**操作流程**：
1. 运行命令：`python -m pdf_tool.pdf_to_text paper.pdf -o output/`
2. 等待转换完成
3. 打开生成的 TXT 文件进行阅读和编辑

### 场景二：批量文档处理
**用户角色**：办公室文员
**场景描述**：用户有一个文件夹包含数十份扫描版合同，需要全部转换为文本格式进行归档。
**操作流程**：
1. 运行命令：`python -m pdf_tool.pdf_to_text contracts/ -o output/`
2. 工具自动处理所有 PDF 文件
3. 生成对应的 TXT 文件

### 场景三：作为库集成
**用户角色**：开发者
**场景描述**：开发者需要在自己的应用中集成 PDF 转文本功能。
**操作流程**：
1. 安装依赖：`pip install -r requirements.txt`
2. 在代码中导入：`from pdf_tool import convert_pdf_to_text`
3. 调用函数进行转换

## 8. 风险与注意事项

### 8.1 技术风险
- 微信 OCR 引擎依赖特定版本的 DLL 文件
- PDF 转图片依赖 poppler 工具
- 识别准确率受图片质量影响

### 8.2 依赖风险
- poppler 需要用户手动安装
- 仅支持 Windows 平台

### 8.3 使用注意事项
- 建议使用清晰度较高的 PDF 文件
- 复杂背景或手写体可能影响识别效果
- 转换过程中需要保持网络断开（可选）以确保隐私安全
